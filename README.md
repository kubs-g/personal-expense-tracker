#  Personal Expense Tracker

A full-stack web application that allows users to register, log in, and track their daily expenses by category. 
Built with React for the frontend and Node.js with PostgreSQL on the backend.

##  Features

- User authentication (signup, login)
- Add, view, and categorize expenses
- Visualize expenses using modern bar charts
- Responsive and clean UI
- Date-based expense tracking

## Tech Stack
### Frontend
- React
- Axios
- Recharts
- CSS 

### Backend
- Node.js
- Express.js
- PostgreSQL
- JSON Web Tokens (JWT)
- bcrypt for password hashing
